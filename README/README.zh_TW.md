BetterVRCX 是一款專為 VRChat 設計的桌面小幫手，協助你管理社交生活、監控動態，並在桌面與 VR 之間切換時保留完整脈絡。在延續 VRCX 強大相容性的同時，提供更清晰、沉浸的全新工作介面。

# 開始使用

<div align="center">

可以從[此處](https://github.com/awakenginexe/BetterVRCX/releases/latest)下載最新的安裝程式（安裝程式名稱為 `BetterVRCX_Setup.exe`）。

# 功能特色

<div align="left">

- :family: 好友、世界與虛擬化身列表管理
    - 在 VRChat 外部管理你的好友列表、世界/群組/虛擬化身列表。
    - 監控好友的活動狀態、在線狀態、所在世界與化身變更。
    - 記錄好友新增日期、共處時間以及歷史更名記錄。
    - 儲存備忘筆記，方便記住彼此是如何相識的。
- :bar_chart: 自訂儀表板與小工具
    - 建立個人化的多面板佈局，包含動態（Feed）、遊戲日誌（GameLog）及即時房間小工具。
    - 建立多個獨立儀表板，各自具備可自訂的事件篩選與欄位顯示。
- :mag: 強大的全實體搜尋
    - 搜尋使用者、世界、化身與群組，亦可直接貼上 ID 或 URL 快速開啟。
    - 快速搜尋（Quick Search）提供即時模糊搜尋好友、化身、世界及群組。
- :chart_with_upwards_trend: 線上活動熱力圖
    - 透過 星期 × 小時 的熱力圖視覺化使用者的在線時間與巔峰時段。
- :camera: 在遊戲內拍攝的照片中儲存世界資料，方便在數個月後隨時回溯拍攝地點！
- :bell: 監控並回應即時通知
    - 透過 BetterVRCX 傳送/接收邀請與好友請求，並直接檢視邀請中的房間資訊。
- :scroll: 檢視目前房間的玩家名單與詳細統計數據。
- :tv: 檢視目前世界中正在播放的影片連結以及其他記錄數據。
- :performing_arts: 社交狀態預設集
    - 快速儲存並套用狀態文字與描述組合。
- :rotating_light: VRChat 伺服器狀態即時監控
    - 狀態列與登入畫面即時提醒伺服器異常或斷線情況。
- :bar_chart: 增強版 Discord Rich Presence
    - 在 Discord 上顯示詳細的即時房間資訊，包含世界縮圖、名稱、玩家人數以及公開房間的加入按鈕。
- :crystal_ball: VR 懸浮疊加層，可自訂即時事件與通知推送。
- :outbox_tray: 無需開啟 Unity 即可上傳並管理化身/世界圖片與詳細資料。
- :electric_plug: 啟動 VRChat 時自動啟動輔助程式。
- :skull: 當 VRChat 當機時自動重新啟動並返回最後的房間。
- :left_right_arrow: 資料匯出與匯入。

## BetterVRCX 是否違反 VRChat 服務條款？

**沒有。**

BetterVRCX 是一個透過 VRChat API 提供輔助功能的外部工具。

它不會以任何方式修改遊戲檔案，僅以負責任的方式使用官方 API。它不是 Mod、外掛或任何形式的遊戲修改。

若想了解 VRChat 對 API 使用的政策，請參閱 VRChat 官方 Discord 的 #faq 頻道。
